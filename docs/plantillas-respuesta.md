# Plantillas de respuesta para WhatsApp y correo

Son para copiar, cambiar lo que va entre [CORCHETES] y mandar. Lo que va entre corchetes es un dato que solo tú sabes: un nombre, una fecha, un precio. No mandes ninguna con los corchetes puestos.

Contesta el mismo día si se puede, porque quien pide cotización muchas veces también está escribiendo a otras carpinterías.

## 1. Primer contacto

### Cocina

**WhatsApp**

```

Para darte una primera idea, ¿me ayudas con esto?
1. ¿En qué fraccionamiento o colonia está tu casa?
2. ¿Tienes el plano o medidas aproximadas de la cocina? Una foto del espacio también sirve.
3. ¿Qué aparatos vas a usar? (estufa o parrilla, horno, refrigerador, campana)
4. Si tienes fotos de cocinas que te gusten, mándamelas.
```

## 2. Pedir medidas o plano

```
¡Gracias, [NOMBRE]! Para avanzar con el diseño necesito el plano de tu casa o las medidas del espacio.

Si no tienes plano, con esto basta:
- Largo de cada muro donde va el mueble.
- Altura del piso al techo.
- Dónde están puertas, ventanas, contactos y tomas de agua o gas.

Una foto de frente al espacio ayuda mucho. Si prefieres, vamos a medir nosotros: dime qué día te queda bien.
```

## 5. Seguimiento

### A los 3 días

```
Hola, [NOMBRE]. ¿Pudiste revisar la cotización de tu [PROYECTO]? Si tienes dudas sobre el diseño, los materiales o los pagos, aquí estoy.
```

### A los 7 días

```
Hola, [NOMBRE]. Te escribo para saber cómo vas con tu [PROYECTO]. Si el presupuesto no te cuadra, podemos ver otro material o ajustar el diseño para acercarnos a lo que tienes pensado. ¿Lo platicamos?
```

Si después de este mensaje no contesta, no vuelvas a escribir en ese mes. Un tercer mensaje seguido se siente como presión.

## 6. Cuando dicen que no

```
Gracias por avisarme, [NOMBRE], y por tomarnos en cuenta. Si más adelante quieres retomar el proyecto o necesitas algo más para tu casa, aquí estamos.

Te dejo nuestra página por si quieres ver otras obras: www.mymce.com.mx
```

Si te dicen por qué no (precio, tiempo, otro proveedor), anótalo. Con varias respuestas así se ve qué conviene cambiar.
