# Tickets del sitio

Cada archivo es un ticket con su `Status:`:

- `not started`: no se empieza sin que el dueño lo pida.
- `in progress`: el ticket manda sobre el código a medio hacer.
- `completed`: el código manda; si difiere, el ticket quedó viejo.
- `dropped`: descartado a propósito. No se implementa ni se vuelve a proponer.

Al terminar un ticket, cambia su `Status:` en el mismo turno.
